# Progress reports

Week, month, and year reports are available from each activity. Reports count progress
against historical targets, list open and partial goals separately, and display the full
range for weekly goals assigned to a month or year. The calendar lists counts on actual dates.

The iOS 27.2 simulator suite passed with 28 domain tests and three UI tests. The UI history
flow opened Progress reports and found the calendar before continuing to edit a log.
The later focused run passed four report tests, including a ten-year fixture with 25 habits
and 91,325 goal periods. The yearly calculation took about 8 ms in that run.

Local evidence is in `.build-evidence/t06-suite.log` and `.build-evidence/t06-fixture.log`.
Xcode listed only the simulator. Physical report responsiveness and D2 remain unverified.
